# Django Master Course — Flix API Project

A learning project developed while following the Django Master course. Built with Python and Django, this application introduces REST API development through a genre management system, covering endpoint creation, resource retrieval, and CRUD operations.

The project focuses on understanding HTTP methods, API resource management, and testing requests using Postman.

- Django
- Django REST Framework
- HTTP and REST APIs
- Postman
